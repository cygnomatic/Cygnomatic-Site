# RoboMaster视觉组 2026赛季 招新测试题

你们好，机器人爱好者们！

欢迎来到RoboMaster视觉组的招新挑战。无论你是初窥门径的新手，还是身怀绝技的高手，我们都为你准备了量身定制的挑战。

我们相信，对技术的热情和解决问题的能力是成为一名优秀机器人工程师的关键。在这里，你将有机会通过一系列独立的、贴近真实机器人应用场景的挑战，全面展示你的才华。

**请根据你目前的技术水平和希望挑战的难度，从以下两个入口中选择一个开始你的征途。**



## **入口一：基础挑战**

这个入口适合**渴望学习、希望从零开始体验机器人视觉开发乐趣**的你。

在这里，你将通过一系列入门级任务，掌握Linux开发环境、核心编程技能、基础算法和计算机视觉的基本应用。这不仅是对你现有能力的检验，更是一次快速成长的学习之旅。

我们期待看到你清晰的逻辑、规范的代码和强大的学习潜力。

➡️ **[点击这里，开始你的挑战](/recruit/vision/exam/easy)**

---

## **入口二：进阶挑战**

这个入口适合**对计算机科学有一定理解、具备编程经验、渴望挑战复杂工程问题**的你。

在这里，你将直面一个综合挑战，涵盖从底层环境自动化、并发编程、高级算法设计，到ROS2系统集成和深度学习模型训练的全过程。这不仅考验你的编码能力，更考验你的系统设计思维、工程实践规范和解决前沿问题的能力。

我们期待看到你卓越的工程设计、严谨的解决方案和对技术深度的不懈追求。

➡️ **[点击这里，开始你的挑战](/recruit/vision/exam/hard)**

---

**无论你选择哪个入口，请记住：**

* **独立思考与主动学习** 是我们最看重的品质。

* **清晰的文档 (`README.md`)** 和 **规范的Git提交** 是你工程素养的体现。

  

**记住兴趣与探索欲是你最好的老师**
