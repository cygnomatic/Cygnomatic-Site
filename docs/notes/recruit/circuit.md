# 2026赛季逐雁硬件组招新

## 硬件组简介

硬件组准确的说是电路组，是设计电路和对应电路板让机器人在实际上从无到有的过程。只有有了硬件，代码才有了在现实中实现的可能。

来到硬件组，你将学习相应的电路设计方法、电磁仿真、芯片选型等，同时你将学习怎么设计电路板，怎么考虑工艺和需求的取舍，如何根据需求确定参数等知识和技能。

当然，你也要面临电容爆炸，电感起火，芯片烧毁，电线断裂，尺寸错误等诸多挑战。如果说视觉决定了机器人的上限，那么硬件就是其现实的凭依与下限之一。相信热爱挑战自我的你，也一定能在这里突破自己的极限！

## 我可以得到什么？

1. 参加2026 RoboMaster 机甲大师 系列竞赛。
2. 学习电路板的设计，电路仿真、电磁场仿真、选型等。
3. 提前在实际应用中学习模电数电信号与系统等课程内容。
4. 熟悉现代电子设计步骤与流程（包括采购等）。
5. 提升自身学习能力、沟通能力、团队合作能力等。

## 招新要求

### 基本要求

1. ==具有基本的电学常识，最好能熟悉基本的电子元件。==
    - 诚然您不需要熟练掌握模电，更毋需独立分析逻辑电路构成之能力。但是最基本的欧姆定律希望您仍然记得。
    - 此外，我们仍然期待您有基本的电路分析能力，希望您可以对工程应用场景下的电路图胸有丘壑。
2. ==有较强的阅读能力，信息检索能力。==
    - 由于大部分电子元件是英文文档，您需要在绘制硬件图时阅读英文原文档，进行六级或雅思的备考。耐心阅读，提取出繁杂外文条目中自己需要的那一部分。
    - 希望您在工作的时候脚踏实地，多想一想参数是怎么来的，怎么近似的。
3. ==每周有效工作时间应当超过15小时。==
    - RoboMaster终究不是RoboPPT，不是用Office或者WPS能完成备赛的。从头设计大量的机器人并在电路层面上确保稳定意味着作为新人的您需要大半年的时间，每周10小时以上的工作时间甚至是备赛关键期在实验室休息的心里准备。
    - 以上条件意味着您在参加RM的时候不太可能能同时参加RC/ACM等，也请您谨慎选择。
4. ==（面试基本要求）安装立创EDA。==
    - 立创EDA是目前简中环境使用最广泛的EDA软件，硬件组所有新成员推荐使用立创EDA进行PCB设计。当然KiCAD等软件自然允许，前提是您能熟练使用。
    - 新人还是推荐使用立创EDA，毕竟简中开发者的作品，最适合新手国人使用。
    - 立创EDA的具体安装教程见文末常见问题。

    ::: danger
    硬件组组长: “不装立创EDA面试时我会直接请您离开。如果您能熟练使用KiCAD，我会对您崇拜至极”
    :::

### 加分项

1. 有相关项目/比赛者优先。即使您参加的项目和硬件无关或者您的职责不是硬件，也欢迎提供相关信息。关键词：电赛、智能车、物理竞赛、集创赛、蓝桥杯（仅限EDA、嵌入式组）。
2. 有基本的PCB设计经验、元器件使用经验（包括NE555）者优先。

## 招新流程

26赛季硬件组招收2026赛季==正式成员==和==梯队成员==。
-我们将在9月中旬至10月中旬进行线下集训，集训完成即进行考核与面试。根据综合表现分数高低分流为正式成员与梯队成员。（面试与考核权重均为50%）
- ==正式成员== 以准备2026赛季RoboMaster联盟赛与超级对抗赛为核心任务。将在考核结束后立刻开始备赛，若成功参加26赛季RoboMaster全国大学生机器人大赛，将获取获奖证书。欢迎各年级同学报名。
- ==梯队== 以准备2027赛季RoboMaster与2026赛季ROBOCON为核心，适合测试中尚嫌稚嫩的同学。我们将通过继续培训与适当摊派备赛任务完成查缺补漏。同样欢迎各年级同学报名。
