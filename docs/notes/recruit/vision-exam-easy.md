## **RoboMaster视觉组招新测试题（易）**

**致机器人爱好者：**

你好！欢迎来到RoboMaster视觉组的测试。

这份测试题旨在考察你的编程基础、逻辑思维和学习新知识的能力。每个关卡都模拟了机器人在执行任务时的一个小侧面，让你能初步体验到用代码驱动机器的乐趣。

### **第一部分：理论理解题**

**背景:** 在动手之前，我们希望你对RoboMaster视觉组的工作和相关技术有一个基本的认识。

**任务:** 请仔细阅读[**《了解CV和RoboMaster视觉组》**](https://github.com/NeoZng/vision_tutorial/blob/main/%E4%BA%86%E8%A7%A3CV%E5%92%8CRoboMaster%E8%A7%86%E8%A7%89%E7%BB%84.md)文档，并根据你的理解回答以下问题（请将答案写在`task1_theory/README.md`中）：

1.  **（阅读第2.1节）** 文档中提到了“小陀螺”是赛场上的一种经典战术，请简述它为什么会给传统的自瞄算法带来巨大挑战？
2.  **（阅读第6.1.1.1节）** 在使用传统视觉方法识别装甲板时，文档中提到通常需要**降低相机曝光**。请结合你自己的理解，解释为什么低曝光设置对提取亮着的灯条特征更有利？
3.  **（阅读第3.1节）** 文档花了很多篇幅介绍为什么视觉开发推荐使用 **Ubuntu (Linux)** 系统而不是Windows，请总结一下作者给出的至少三个主要理由。
4.  **（阅读第5.0节）** 请用你自己的话，简要描述**图像分类 (Image Classification)** 和**目标检测 (Object Detection)** 这两个任务的核心区别是什么？
5.  **（阅读第5.6.3节 - 相机标定）** 文档提到，由于镜头制造工艺等原因，相机会产生“畸变”（Distortion）。请用你自己的话简单描述什么是图像畸变，以及为什么在进行精确测量前，我们需要对相机进行标定（Calibration）？

### **第三部分：战术指令系统**

**背景:** 机器人需要接收并解析明确的指令才能行动。本关旨在考察你的基础编程和数据处理能力。

#### **C++ 方向**

1.  **指令日志分析器:**
    
    *   **任务:** 编写一个C++程序，它接收一个**命令行参数**作为日志文件的路径，读取该文件，统计并打印出每种指令各自执行了多少次。
    * **测试**
      请在你的项目中创建 `commands.log` 文件，并使用以下内容作为测试数据：
    
      ```
      MOVE
      SHOOT
      MOVE
      SCAN
      SHOOT

      ```

#### **Python 方向**

1.  **机器人状态配置:**
    *   **任务:** 编写一个Python程序，它接收一个**命令行参数**作为配置文件的路径，读取该JSON文件，并将其中的信息格式化地打印出来。

### **第四部分：战场寻路**

**背景:** 在复杂的战场环境中，机器人需要能够自主规划路径以躲避障碍。

**任务：寻找安全路径**
1.  **场景:**
    给定一个由`0`和`1`组成的二维地图，`0`代表平地，`1`代表障碍物。
2.  **实现:**（C++/Python）
    
    - **算法:** 使用**广度优先搜索 (BFS)** 或**深度优先搜索 (DFS)** 算法。
    
    - **任务:** 编写一个函数或程序，它接收一个**命令行参数**作为地图文件的路径，读取地图，并判断从固定的起点S到终点E是否存在路径。
    
    - **正式测试文件 `maze.txt` 内容:** 请在你的项目中创建 `maze.txt` 文件，并使用以下内容（S在左上角(0,0)，E在右下角(4,4)）：
    
      ```
      S.##.
      .#.#.
      .#..#
      ##.##
      ...#E
      ```
    
    - **输出:** 如果路径存在，程序应在标准输出打印 `Path found.`；如果不存在，则打印 `No path found.`。
    
    - **测试要求:** 你的 `test.sh` 脚本应能编译（如果需要）并像这样运行它：`./your_program_name maze.txt`

### **第五部分：目标识别入门**

**背景:** 视觉是机器人的核心感知能力。本关旨在让你体验如何从图像中提取有用信息。

**任务一：识别敌方机器人颜色**

**实现:**

*   **输入:** 一张包含红色物体的静态图片。
*   **参考流程:**
    1.  使用OpenCV加载图片。
    2.  将图片从BGR色彩空间转换到HSV色彩空间。
    3.  设定红色的HSV阈值范围，生成一个只包含红色区域的二值化掩码（Mask）。
    4.  显示原始图片和提取出的红色区域掩码。
*   **任务:** 编写一个程序，接收一个**命令行参数**作为图片路径，加载图片，设定红色的HSV阈值范围，最后显示原始图和处理后的二值化掩码图。
*   **测试要求:** 由于该任务需要显示窗口，学长学姐会手动运行你的程序进行验证，请在`README.md`中写明运行命令，例如：`./your_program_name path/to/your/test_image.jpg`。你的`test.sh`脚本可以包含这个示例命令。

**任务二：定位能量机关（ROI与形状检测）**

**实现:**

*   **输入:** 一张能量机关的简化模拟图（例如，白纸上画一个黑色实心圆）。
*   **参考流程:**
    1.  加载图片并进行灰度化和二值化处理。
    2.  使用OpenCV的 `findContours` 函数来寻找图中的所有轮廓。
    3.  通过一些简单的几何判断（例如，通过轮廓的面积和圆度）来筛选出最可能是圆形的那个轮廓。
    4.  在原图上用一个矩形框（Bounding Box）将这个圆形轮廓标记出来。
*   **任务:** 编写一个程序，接收一个**命令行参数**作为图片路径，加载图片，找到其中最可能是圆形的轮廓，并在原图上用矩形框标记出来后显示。
*   **测试要求:** 由于该任务需要显示窗口，学长学姐会手动运行你的程序进行验证，请在`README.md`中写明运行命令，例如：`./your_program_name path/to/your/test_image.jpg`。你的`test.sh`脚本可以包含这个示例命令。
